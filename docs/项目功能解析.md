# 题屿（shuashuati_app）项目功能解析

> 由 AgentTeams 多智能体协作产出（2026-08-21），基于代码逐文件解析。

## 一、项目总览

### 1.1 定位与技术栈
模块化 Flutter 综合学习应用，三大业务模块 + 核心基础设施。技术栈：

| 领域 | 选型 |
|---|---|
| 状态管理 | flutter_bloc 9.1.1（`Bloc`/`Cubit`，模块级 Bloc + 全局 ThemeCubit） |
| 本地存储 | hive_ce 2.19.3（hive 社区版，18 个 TypeAdapter 由 build_runner 生成） |
| 文件解析 | doc_text_extractor（Word）、archive + xml（xlsx 解压解析） |
| 分享 | share_plus 13.3.0（`SharePlus.instance.share(ShareParams)`）、qr_flutter |
| 游戏引擎 | flame 1.38.0 系列（portalborn 模块依赖） |
| 主题 | 全局 + 每模块独立主题（AppModule.supportsIndependentTheme） |

### 1.2 架构分层
```
main.dart
├── core/       模块注册系统（AppModule/ModuleRegistry）、两级主题、存储服务
├── data/       全局模型（user/notification）与仓库
├── presentation/ 首页（模块卡片网格）、全局搜索、个人中心、通知、存储管理
└── modules/    三个业务模块（quiz 刷题 / timetable 课表 / portalborn RPG）
```
模块通过 `ModuleRegistry` 登记，`HomePage` 以 2 列卡片网格呈现（当前 3 模块 + 1 占位"更多模块"卡）。

## 二、启动链路与核心层

### 2.1 启动流程（main.dart）
`runZonedGuarded` 全局兜底 → `Hive.initFlutter` → `Hive.registerAdapters()`（hive_ce 生成器自动注册 18 适配器）→ 打开 8 个 box（questions/wrong_stats/tower/notifications/timetables/time_tables/courses/portalborn）→ 播种示例通知 → `MyApp`（ThemeCubit 包裹）→ `HomePage`。

> ⚠️ 已移除开发期"启动强制清空全部 Hive box"代码（2026-08 升级时清理）。

### 2.2 模块系统（core/module/）
- `AppModule` 抽象接口：id/title/icon/homePage/enabled/supportsIndependentTheme/defaultTheme，`buildModulePage` 自动按模块主题包裹。
- `ModuleRegistry`：静态模块列表（quiz/timetable/portalborn），`modules` 过滤 enabled，`findById` 查找。

### 2.3 主题（core/bloc/theme_bloc.dart + app_theme.dart）
`ThemeCubit`：全局模式（light/dark/system）+ 每模块独立模式覆盖，`getEffectiveTheme(id)` 计算生效主题；持久化到 Hive `themeSettings` box；根 `MaterialApp` 随全局模式重建。

### 2.4 首页（presentation/pages/home_page.dart）
- 底部两 Tab：主页 / 我的。
- 主页：品牌区 → 搜索栏（入口 GlobalSearchPage）+ 通知铃铛（真实未读数红点，>99 显示 99+）→ SliverGrid 模块卡片（2 列，点击 `push module.homePage`）。
- 模块卡片配色表按模块 id 映射（quiz 蓝 / note 橙 / fitness 绿，未知模块紫）。

### 2.5 数据层（data/）
- `UserModel`（typeId 100）、`NotificationItem`（typeId 99）。
- `NotificationRepository`：未读数、标记已读、示例通知播种。
- `StorageService`：缓存/临时文件清理（白名单模式）。

## 三、刷题模块（lib/modules/quiz/）

### 3.1 数据模型
| 模型 | typeId | 关键字段 |
|---|---|---|
| Question | 0 | id/options/answer/explanation/source/…（**题型无显式 type 字段，靠 options 结构隐式编码**：2 选项且含正确/错误=判断，1 选项含填空=填空，否则=选择） |
| WrongQuestionStats | 2 | questionId/wrongCount/correctCount/masteryLevel/easinessFactor/interval/consecutiveCorrect/lastReviewDate 等 9 字段 |
| TowerProgress | 3 | 18 字段（层数/节点进度/奖励等） |

### 3.2 答题状态机（quiz_bloc.dart + quiz_page.dart）
- **QuizBloc**：20 事件 / 8 状态，负责题目加载、答题判定、进度保存（原序断点续答）。
- **双进度体系**：Bloc 维护原序断点（保存到 Hive），QuizPage 维护页面筛选/显示位（按**题型**筛选：全部/选择/判断/填空），各自持久化。
- 答题判定、错题记录、收藏（toggleFavorite）、跳题（question_jump_dialog）、退出确认保存。

### 3.3 错题本与智能复习（SRS 间隔重复，SM-2 简化版）
- **间隔阶梯**：1 → 3 → 7 → 15 → 30 天 → 之后 ×1.5。
- **EF（易度因子）**：答对 +0.1 / 答错 -0.2，clamp 于 1.3~2.6。
- **mastery（熟练度）**：正确率×0.6 + (1−错题惩罚)×0.4。
- **毕业**：mastery ≥ 0.8 且连续答对 5 次 → 自动移出错题集。
- 页面：wrong_questions（错题集）/ wrong_reinforce（强化练习，背题模式切换）/ review（到期复习）。

### 3.4 闯塔模式（tower_page.dart，无 Bloc 纯页面状态）
- 确定性伪随机节点生成（8 类节点：战斗/问答/宝箱/事件等），Boss 层每 5 层。
- TowerRepository 持久化 TowerProgress；节点事件通过 tower_event_dialog 呈现。

### 3.5 文件导入（file_parser_service.dart）
- **Word（docx）**：5 策略顺序兜底——标准答案区 / 行内答案 / 纯选择 / 紧邻答案模式 / 无答案区。
- **JSON**：兼容 4 形态——裸数组 / `{questions}` / `{data}` / `{list}`。
- 导入走 manual_import（手动编辑）/ example_import（示例）/ quiz_page 追加/导入入口。

### 3.6 分享
- **二维码**（share_qrcode_page）：qr_flutter 生成（仅标识题库名）+ RepaintBoundary 截图 + SharePlus 分享。
- **JSON 导出**：保留题目 id，支持跨设备导入去重。
- 分享中心（share_center_page）：导出 → 分享 / 保存。

## 四、课表模块（lib/modules/timetable/）

### 4.1 数据模型
- `Course`（typeId 30）：课程名/教师/教室/星期/节次（start/end slot）/周次（weekStart/end）/颜色/时间（startMinute）。
- `Timetable`（typeId 31）：name/courseIds/isCurrent/timeTableId。
- `TimeTable`（typeId 32）：作息时段（morningStart=480/afternoonStart=840/classDuration=45/breakDuration=5）。

### 4.2 xlsx 解析（xlsx_parser.dart + timetable_parser_service.dart）
1. `ZipDecoder` 解压 xlsx → `xl/sharedStrings.xml`（si/t 拼接共享字符串）+ `xl/worksheets/sheet*.xml`。
2. cell `r` 引用还原列号；`t="s"` 查共享字符串表；inlineStr 兜底。
3. 找「星期一」表头 → 映射星期列/节次列；单元格按换行分组课程块。
4. 正则提取教师/教室/周次/节次 → 清洗课程名 → `ColorManager` 轮转 12 色。
5. 约束：节次 clamp 1-12、周次 clamp 1-20。
- `parseFile` 自动识别 json/xlsx/xls：**矩阵格式**（≥2 星期列）vs **导出列表格式**（含"课程名称+教师"列），检测失败默认矩阵。

### 4.3 周视图（timetable_week_view.dart）
- Stack 背景网格（DragTarget）+ 课程卡片绝对定位（slot × 64px）。
- `_findCourseAt`：weekday + 周次过滤（showAllWeeks 开关，默认仅本周）+ 时间区间重叠定位（`startMinute ?? (startSlot−1)×45+480`）。
- LongPressDraggable（500ms 延迟）拖放可交换课程。

### 4.4 导入导出分享
- 导入：FilePicker → parseFile → `ImportCourses`（替换当前课表）。
- 导出：JSON 或手搓 xlsx zip（失败降级 JSON）；`lastExportedFilePath` 供分享中心/二维码复用。

## 五、传送门编年史模块（lib/modules/portalborn/）

### 5.1 状态机（portalborn_bloc.dart，1145 行）
- **29 个事件处理器**，六组：生命周期（Load/CreateCharacter/SelectCharacter/SaveGame/Quit）、交互（SubmitCommand/ClickExit/QuickAction）、战斗（Attack/CastSpell/UsePotion/Defend/Flee）、探索（Examine/Search/TakeItem/DropItem/UseItem）、背包制作（ToggleInventory/Equip/Unequip/Craft）、UGC/词条。
- 状态：Loading / MainMenu / Hub / Exploring（可 inBattle）/ Battle / Error 等 7 个状态类（Inventory/Crafting 为 Hub 内的子面板，非独立状态类）。
- `_addMessage` 消息队列（Hub/Exploring 上限 100 条、Battle 日志 50 条）；定时自动存档；死亡惩罚（扣金币+恢复 HP+回入口）。

### 5.2 游戏引擎（game_engine.dart，762 行，纯函数）
- **属性公式**：总攻击 = 基础+武器+max(0,(STR−5)×0.5)；总防御 = 基础+护甲+max(0,(CON−5)×0.3)；最大 HP = 20+CON×2+round(等级×(3+CON×0.2))。
- **物理伤害**：闪避率 = DEX×0.5% → miss；暴击；伤害 = `max(1, ATK − DEF~/2) + 随机(−1~2)`（防御按半数参与）。
- EXP 升级（expForLevel 曲线）、属性成长、掉落。

### 5.3 领域与装备生成
- **RealmGenerator**：选主题（themeDataMap）→ 房间数（主题 min-max）→ 入口+中间+Boss 房 → 出口连接（线性+分支）→ 填充怪物/物件/宝箱（难度随玩家等级缩放）。
- **GearGenerator**：基础物品模板 + 随机词缀（_selectAffixByRarity 稀有度权重，等级限制稀有度上限）→ 词缀名/emoji 前缀拼接 → 应用效果（atk/def/crit/dodge）。

### 5.4 命令解析（command_parser.dart，514 行，单例）
CommandTemplate 模板：移动（n/s/e/w/up/down/portal/go）、战斗（attack/cast/defend/flee）、探索（look/examine/search/take/drop/use）、背包（inventory/equip/unequip）、系统（help/status/save/quit/rest）；支持别名、带参命令（requiresTarget）、分类帮助。`parse()` 分词 → 匹配 → 参数 → ParseResult。

### 5.5 数据与存储（hive_ce，box='portalborn'，键前缀）
| 模型 | typeId | 说明 |
|---|---|---|
| GameCharacter | 33 | 33 字段（属性/装备/背包上限 20/材料/遗产/每日运势） |
| GameItem | 34 | 物品 |
| GameState | 35 | 存档（当前角色/领域/位置） |
| UGCCustomRealm/Room/Exit/Interactable/Monster/Drop/Item | 36-42 | 玩家自定义领域体系 |

### 5.6 种子数据规模（seed_data/）
classes 5 职业 + 25 技能 / items 47 / monsters 30 / recipes 10 / affixes 31 / lore 20 / fortunes 6（每日运势：lucky/unlucky/wise/rich/brave/normal，效果作用于掉落率/暴击/经验/金币/攻击）。

### 5.7 表现层
portalborn_screen 终端风主屏（#00ff88）→ main_menu / create_character / hub / explore / battle / inventory / crafting 页面 + 全套组件（terminal/command_input/status_bar/battle_*/room_card 等）。当前为 **P0 开发阶段**（占位页标注"开发中-P0"），框架+引擎+数据全通，可进测试版游玩。
