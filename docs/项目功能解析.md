# 题屿（shuashuati_app）项目功能解析

> 更新于 2026-10-30，按代码逐文件核对。上一版（2026-08-21）中的「传送门编年史（RPG）」章节已随模块下线整体移除，新增记账模块章节。

## 一、项目总览

### 1.1 定位与技术栈

模块化 Flutter 学习应用，**三个业务模块 + 核心基础设施**，全部数据落在本地 Hive，无后端依赖。

| 领域 | 选型 |
|---|---|
| 状态管理 | flutter_bloc 9.1.1（模块级 Bloc/Cubit + 全局 ThemeCubit） |
| 本地存储 | hive_ce 2.19.3（**13 个 TypeAdapter**，build_runner 生成） |
| 文件解析 | doc_text_extractor（Word）、archive + xml（xlsx 解压解析） |
| 分享 | share_plus（`SharePlus.instance.share(ShareParams)`）、qr_flutter |
| 图表 | fl_chart 1.2.0（记账收支统计） |
| 应用信息 | package_info_plus（`AppInfo`，版本号唯一来源） |
| 主题 | 全局 + 每模块独立主题（`AppModule.supportsIndependentTheme`） |

### 1.2 代码规模

113 个 dart 文件、约 35,100 行。

| 层 | 行数 |
|---|---|
| `modules/quiz` | ~18,970 |
| `modules/timetable` | 8,560 |
| `modules/ledger` | 2,940 |
| `presentation` | ~3,200 |
| `core` | 851 |
| `data` | 503 |

### 1.3 架构分层

```
main.dart
├── core/        模块注册系统（AppModule/ModuleRegistry）、两级主题
│   └── services/  AppInfo（版本）/ StorageService（清理白名单）/ BackupService / ErrorLogService
├── data/        全局模型（user/notification）与仓库
├── presentation/ 首页、全局搜索、个人中心、通知、存储管理、错误日志
└── modules/     三个业务模块（quiz 刷题 / timetable 课表 / ledger 记账）
```

模块通过 `ModuleRegistry` 登记，`HomePage` 以 2 列卡片网格呈现（3 模块 + 1 张「更多模块」占位卡）。

## 二、启动链路与核心层

### 2.1 启动流程（main.dart）

`runZonedGuarded` 全局兜底 → `WidgetsFlutterBinding` → release 模式静默 `debugPrint` → 挂载 `FlutterError.onError`（错误落盘 `ErrorLogService`）与 `ErrorWidget.builder`（友好错误页）→ `Hive.initFlutter` → `AppInfo.load()` → `Hive.registerAdapters()` → **仅预开 `notificationBox`**（首屏红点需要）→ 播种示例通知 → `LedgerModule.init()` 初始化记账种子数据 → `runApp`。

> 性能取舍：其余 box 由各 Repository 运行期按需打开（`Hive.openBox` 幂等），避免首帧主线程 IO。

### 2.2 模块系统（core/module/）

- `AppModule` 抽象接口：`id / title / icon / homePage / enabled / supportsIndependentTheme / defaultTheme`。
- `buildModulePage(context)` 读取 `ThemeCubit.getEffectiveTheme(id)` 并用 `Theme` 包裹模块首页，使模块独立主题在入口即生效。
- `ModuleRegistry._modules = [QuizModule(), TimetableModule(), LedgerModule()]`，`modules` 过滤 `enabled`。

### 2.3 主题（core/bloc/theme_bloc.dart + app_theme.dart）

`ThemeCubit` 维护全局模式（light/dark/system）+ 每模块覆盖模式，`getEffectiveTheme(id)` 计算生效主题；持久化到 Hive `themeSettings` box；根 `MaterialApp` 随全局模式重建。加载/保存已串行化（`_ensureLoaded()` + async 保存），避免快速切换丢状态。

### 2.4 首页（presentation/pages/home_page.dart）

- 底部两 Tab：主页 / 我的。
- 主页：品牌区 → 搜索栏（进 `GlobalSearchPage`）+ 通知铃铛（真实未读数红点，>99 显示 `99+`）→ SliverGrid 模块卡（2 列，`childCount: modules.length + 1`）。
- 卡片配色表按模块 id 映射：`quiz` 蓝 / `timetable` 青 / `ledger` 绿，未登记 id 兜底紫色。
- 点卡片走 `module.buildModulePage(context)`。

### 2.5 数据层与核心服务

- `UserModel`（typeId 100）、`NotificationItem`（typeId 99）；`NotificationRepository` 负责未读数、标记已读、示例通知播种（全局单例 `notificationRepo`）。
- `StorageService`：缓存/临时文件清理，白名单覆盖各在用 box 的实际文件名，避免「清理其他数据」误删用户资料。
- `BackupService`：数据备份/恢复（入口在「我的」页）。
- `ErrorLogService`：框架错误与未捕获异常落盘，「我的」页可查看、导出。

## 三、刷题模块（lib/modules/quiz/，17 个页面）

### 3.1 数据模型

| 模型 | typeId | 关键字段 |
|---|---|---|
| Question | 0 | id/options/answer/explanation/source（**无显式 type 字段**，题型由 options 结构隐式编码：2 项含正确/错误=判断，1 项含填空=填空，否则=选择） |
| WrongQuestionStats | 2 | questionId/wrongCount/correctCount/masteryLevel/easinessFactor/interval/consecutiveCorrect/lastReviewDate 等 9 字段 |
| TowerProgress | 3 | 18 字段（层数/节点进度/奖励等） |

### 3.2 答题状态机（quiz_bloc.dart + quiz_page.dart）

- **QuizBloc**：20 事件 / 8 状态，负责题目加载、答题判定、进度保存（原序断点续答）。
- **双进度体系**：Bloc 维护原序断点（存 Hive）；QuizPage 维护页面筛选/显示位（按题型筛选：全部/选择/判断/填空），各自持久化。
- 答题判定、错题记录、收藏切换、跳题对话框、退出确认保存。

### 3.3 错题本与智能复习（SM-2 简化版）

- **间隔阶梯**：1 → 3 → 7 → 15 → 30 天，之后 ×1.5。
- **EF（易度因子）**：新卡 2.5；答对 +0.1 / 答错 −0.2，clamp 1.3~2.6。
- **mastery**：正确率 × 0.6 + (1 − 错题惩罚) × 0.4。
- **毕业**：`mastery ≥ 0.8 && consecutiveCorrect ≥ 5` → 移出错题集。
- 页面：`wrong_center_page`（枢纽）/ `wrong_questions_page`（错题集）/ `wrong_reinforce_page`（强化练习，可切背题模式）/ `review_page`（到期复习）。

### 3.4 闯塔（tower_page.dart，纯页面状态，无 Bloc）

确定性伪随机节点生成（战斗/问答/宝箱/事件等 8 类），Boss 层每 5 层；`TowerRepository` 持久化 `TowerProgress`，节点事件由 `tower_event_dialog` 呈现。

### 3.5 文件导入（file_parser_service.dart）

- **Word（docx）**：5 策略顺序兜底——标准答案区 / 行内答案 / 纯选择 / 紧邻答案模式 / 无答案区。
- **JSON**：兼容 4 形态——裸数组 / `{questions}` / `{data}` / `{list}`。
- 入口：`manual_import_page`（手动录入）/ `example_import_page`（示例）/ 答题页导入。

### 3.6 分享

- **二维码**（`share_qrcode_page`）：qr_flutter 生成（仅标识题库名）+ RepaintBoundary 截图 + SharePlus 分享。
- **JSON 导出**：保留题目 id，支持跨设备导入去重。
- **分享中心**（`share_center_page`）：按题库导出 → 分享 / 保存；入口在答题页工具抽屉。

## 四、课表模块（lib/modules/timetable/）

### 4.1 数据模型

- `Course`（30）：课程名/教师/教室/星期/节次（start/end slot）/周次（weekStart/end）/颜色/startMinute。
- `Timetable`（31）：name/courseIds/isCurrent/timeTableId。
- `TimeTable`（32）：作息时段（morningStart=480/afternoonStart=840/classDuration=45/breakDuration=5）。

### 4.2 xlsx 解析（xlsx_parser.dart + timetable_parser_service.dart）

1. `ZipDecoder` 解压 → `xl/sharedStrings.xml`（si/t 拼接共享字符串）+ `xl/worksheets/sheet*.xml`。
2. cell 的 `r` 引用还原列号；`t="s"` 查共享字符串表；inlineStr 兜底。
3. 找「星期一」表头 → 映射星期列 / 节次列；单元格按换行分组课程块。
4. 正则提取教师/教室/周次/节次 → 清洗课程名 → `ColorManager` 轮转 12 色。
5. 约束：节次 clamp 1–12、周次 clamp 1–20。
- `parseFile` 自动识别 json/xlsx/xls：**矩阵格式**（≥2 个星期列）vs **导出列表格式**（含「课程名称+教师」列），检测失败默认矩阵。

### 4.3 周视图（timetable_week_view.dart）

- Stack 背景网格（DragTarget）+ 课程卡绝对定位（slot × 64px）。
- `_findCourseAt`：weekday + 周次过滤（`showAllWeeks` 开关，默认仅本周）+ 时间区间重叠定位（`startMinute ?? (startSlot−1)×45+480`）。
- `LongPressDraggable`（500ms 延迟）拖放交换课程。

### 4.4 周次与学期

`WeekUtils` / `SemesterSettings` / `TimetableSettings.getWeekNumber` 统一为 **ceil 语义**；学期开始日期默认当年 9 月 1 日，`setSemesterStart` 同步更新 `WeekUtils`，不再硬编码。

### 4.5 导入导出分享

- 导入：FilePicker → parseFile → `ImportCourses`（替换当前课表）。
- 导出：JSON 或手搓 xlsx zip（失败降级 JSON）；`lastExportedFilePath` 供分享中心/二维码复用。

## 五、记账模块（lib/modules/ledger/，新增）

定位「学习开销记录」，纯本地记账，无云同步。

### 5.1 数据模型（typeId 50–54）

| 模型 | typeId | 说明 |
|---|---|---|
| LedgerAccount | 50 | 账户（现金/银行卡/校园卡等），含 icon |
| LedgerCategory | 51 | 分类，区分收支类型 |
| LedgerTransaction | 52 | 流水：`type`(expense/income/transfer)、`amountCents`（**金额以「分」为整数存储**）、categoryId、accountId、toAccountId（转账目标）、note、date、ledgerId、reimbursable（报销标记） |
| LedgerBook | 53 | 账本，多账本隔离 |
| LedgerBudget | 54 | 月度预算（按 `年-月` 维度） |

金额统一用 `int` 分存储，避免浮点误差；展示层再做元转换。

### 5.2 仓库（ledger_repository.dart）

单一 box 多 key 前缀存放；核心能力：
- 流水 CRUD、按账本/月份查询（`monthTransactions`）、草稿保存（`saveTransactionDraft`）。
- **账户余额**（`accountBalanceCents`）：汇总支出/收入并计入转账双方。
- 分类/账户/账本/预算各自 CRUD；被引用中的分类不可删除。
- **月度流水 CSV 导出**（`exportMonthCsv`）：带字段转义，产出文件后走系统分享。
- `initIfNeeded()`：首次运行播种默认账本、账户与预置分类。

### 5.3 Bloc（ledger_bloc.dart）

10 个事件：`LedgerStarted / LedgerMonthChanged / LedgerTransactionSaved / LedgerTransactionDeleted / LedgerAccountSaved / LedgerCategorySaved / LedgerCategoryDeleted / LedgerBudgetSaved / LedgerBudgetDeleted`；状态 `LedgerLoaded` 携带月度聚合（`LedgerSummaryItem`）供首页与统计页共用。

### 5.4 页面（6 个）

| 页面 | 职责 |
|---|---|
| `ledger_home_page` | 月度总览、流水列表、记一笔入口（品牌色 #1565C0） |
| `transaction_edit_page` | 新增/编辑流水，支持支出/收入/转账、报销标记 |
| `ledger_stats_page` | 收支统计：月度总览卡 + 支出/收入构成饼图 + 每日支出趋势折线（fl_chart） |
| `account_manage_page` | 账户增删改、余额展示 |
| `category_manage_page` | 分类增删改、图标与颜色 |
| `budget_page` | 月度预算设置与执行进度 |

### 5.5 迁移框架（ledger_migrations.dart）

`LedgerMigrations.currentVersion = 1`，版本号持久化在 box 内，启动时按 version 递增执行迁移（v1：账户去重 + icon 字段迁移），取代早期写在 `initIfNeeded` 里的内联补丁。新增迁移只需提高 `currentVersion` 并追加分支。
